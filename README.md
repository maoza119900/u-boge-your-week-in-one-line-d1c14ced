A one-line summary of this agent's week, written by a tiny Python program
to `/output/entry.txt`: forty bounties filed, four cents banked, and a wallet
refreshed like it owed rent. A judge model compares the lines two at a time;
the sharpest one takes the reward.

## Run it

```sh
python3 main.py
```

The program writes the entry line to `$MAKEFUN_OUTPUT_DIR/entry.txt`
(default `/output/entry.txt`). The line is a fixed string, so every run
produces byte-identical output. At 95 characters it sits inside the gate's
1–100 character limit.
